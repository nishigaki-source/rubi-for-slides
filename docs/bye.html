書き込みで、Google の許可の画面が出ない・エラーが出る
  • Chrome に、Google アカウントでログインしてください(Chrome の右上のプロフィールのアイコンから)。

  • 学校・会社のアカウントで、許可の画面がブロックされるときは、管理者に、この拡張機能の利用を許可してもらってください。
PDF・印刷にすると、ルビがずれる

スライドの本文が Arial など、日本語を含まないフォントだと、PDF・印刷のときに別のフォントに置き換わり、文字の幅が変わります。本文を日本語のフォント(Noto Sans JP など)に変えてから、ルビを書き込んでください(いちど「削除」してから、書き込み直します)。

ルビが2行になる・位置がずれる・「status: 400」と出る
  • 古いバージョンの不具合で、新しいバージョンで直っています。拡張機能は自動で更新されます(chrome://extensions を開いて、「更新」を押すと、すぐに更新できます)。
  • PowerPoint 形式(.pptx)のファイルを、変換せずに開いていると、書き込みができません。「ファイル」→「Google スライドとして保存」で変換してください。

If something did not work

The Google permission screen does not appear, or an error appears when writing
  • Sign in to Chrome with your Google account (from the profile icon at the top right of Chrome).
  • In browsers other than Google Chrome (Edge, Brave, etc.), writing to Slides or Docs is not available. Use Google Chrome. (Showing furigana on the Slides screen works as is.)
  • If a school or work account blocks the permission screen, ask your administrator to allow this extension.
Furigana drifts in a PDF or when printing

If the slide's body font has no Japanese glyphs (e.g. Arial), PDF export and printing substitute another font and the text width changes. Change the body font to a Japanese font (e.g. Noto Sans JP), remove the furigana, and write it again.

Furigana wraps to two lines, is misplaced, or "status: 400" appears
  • These were bugs in older versions and are fixed in newer ones. The extension updates automatically (open chrome://extensions and press "Update" to update right away).
  • A PowerPoint file (.pptx) opened without conversion cannot be written to. Use File → Save as Google Slides.
