日本語 / English

この拡張機能について

「ルビふり for Googleスライド」は、Googleスライドの編集画面上で日本語テキスト中の漢字にひらがなのルビ(ふりがな)を表示し、 必要に応じて実際のテキストボックスとしてスライドに書き込むためのChrome拡張機能です。

収集する情報

この拡張機能は、開発者が運営するサーバーへ利用者の情報を送信・収集することは一切ありません。

  • アクセス解析(アナリティクス)・広告・トラッキングの仕組みは組み込んでいません。
  • 氏名・メールアドレス・アカウント情報などの個人情報を取得・保存することはありません。

利用する情報とその目的

  • 表示設定・ユーザー辞書(chrome.storage.sync)
    ルビの表示ON/OFF・サイズ・フォント・色・学年フィルタ、および利用者が登録した単語ごとの読み・見た目の設定を、 Chromeの同期ストレージに保存します。これは利用者ご自身のGoogleアカウントに紐づくChromeの同期機能であり、 開発者のサーバーには一切送信されません。
  • Googleスライドの内容(Google Slides API)
    「スライドへの書き込み」機能を使う際、利用者の明示的な操作とGoogleアカウントでの認可(OAuth、 drive.file スコープ)に基づき、利用者がGoogle Pickerで選択したプレゼンテーションに限って、 テキスト内容の取得、およびルビ用テキストボックスの追加・削除を行います。選択していないファイルにはアクセスしません。 この通信は利用者のブラウザとGoogle自身のサーバー(slides.googleapis.com)の間で直接行われ、 開発者がこの内容を閲覧・収集・保存することはありません。
  • Google Picker(ファイル選択画面)
    アクセスを許可するスライドを選ぶため、当サイトの静的ページ(rubi.rocketdone.com/picker.html)で Google Picker(apis.google.com)を表示します。このページは選択結果を拡張機能に返すだけで、 スライドの内容や識別情報を開発者のサーバーに送信・保存することはありません。
  • Googleフォント(Google Fonts)
    ルビのフォントとしてOS標準以外のフォント(Webフォント)を選んだ場合、そのフォントファイルを fonts.googleapis.com から読み込みます。この際、Google のフォント配信に関するプライバシーポリシーが適用されます。

使用しているデータ

「漢字ごと」にルビを振るための漢字の読みデータ(拡張機能に同梱。外部との通信はありません)は、 KANJIDIC2 (Electronic Dictionary Research and Development Group)を CC BY-SA 4.0 のもとで使用し、常用漢字・人名用漢字の音読み・訓読みを抜き出したものです。

権限について

  • storage: 上記の表示設定・ユーザー辞書の保存に使用します。
  • identity: Google Slides APIを利用するためのOAuth認可(ログイン済みのGoogleアカウントでの許可。drive.file スコープ)に使用します。
  • activeTab / Googleスライドへのホスト権限: 現在開いているGoogleスライドの編集画面でのみ動作するために使用します。

データの保持・削除

表示設定・ユーザー辞書は、利用者が拡張機能をアンインストールするか、Chromeの同期データを削除するまで保持されます。 スライドへの書き込み機能で作成したルビ用テキストボックスは、パネルの削除機能、または通常のGoogleスライドの編集操作(元に戻す・削除)で いつでも取り除くことができます。

Google ユーザーデータの取り扱い(Limited Use)

この拡張機能による、Google API から受け取った情報の利用および他のアプリへの転送は、 Google API サービスのユーザーデータに関するポリシー (Limited Use の要件を含む)に準拠します。

  • Google スライドのデータは、ユーザーが求めた機能(ルビの書き込み・削除)を提供する目的でのみ使用します。
  • データを開発者のサーバーへ送信・保存することはなく、第三者への提供・転送・販売も行いません。
  • 広告(パーソナライズド広告を含む)の表示や、ユーザーのプロファイリング、データブローカー等への提供には一切使用しません。
  • 開発者を含む人間がデータを閲覧することはありません(すべての処理はユーザーのブラウザ内で完結します)。

第三者提供

この拡張機能が収集・処理する情報を第三者に販売・提供することはありません。

Privacy Policy (English)

About this extension

"ルビふり for Googleスライド" (Furigana for Google Slides) is a Chrome extension that displays hiragana reading aids (furigana/ruby text) over kanji in the Google Slides editor, and optionally writes them into the slide as real text boxes.

Information we collect

This extension does not send or collect any user information to a server operated by the developer.

  • No analytics, advertising, or tracking is embedded in this extension.
  • No personal information (name, email address, account information) is collected or stored.

Information used and its purpose

  • Display settings and user dictionary (chrome.storage.sync)
    Ruby display on/off, size, font, color, grade filter, and per-word reading/style overrides you register are stored in Chrome's sync storage, tied to your own Google account's Chrome sync. This never passes through a developer-operated server.
  • Google Slides content (Google Slides API)
    When you use the "write to slide" feature, based on your explicit action and Google account authorization (OAuth, the drive.file scope), the extension reads the text content of, and adds/removes ruby text boxes in, only the presentation you selected in Google Picker. It cannot access any file you have not selected. This communication happens directly between your browser and Google's own servers (slides.googleapis.com); the developer never views, collects, or stores this content.
  • Google Picker (file selection dialog)
    To let you choose which presentation to grant access to, a static page on this site (rubi.rocketdone.com/picker.html) shows Google Picker (apis.google.com). The page only returns your selection to the extension; it does not send or store the content or identity of your presentation on any server operated by the developer.
  • Google Fonts
    If you select a non-system (web) font for the ruby text, its font file is loaded from fonts.googleapis.com. Google's own privacy policy for font delivery applies to this request.

Data used

The kanji reading data used for per-kanji furigana (bundled with the extension; no network access) is extracted from KANJIDIC2 by the Electronic Dictionary Research and Development Group, used under CC BY-SA 4.0 (on/kun readings of jōyō and jinmeiyō kanji).

Permissions

  • storage: used to store the display settings and user dictionary described above.
  • identity: used for OAuth authorization (the drive.file scope) to call the Google Slides API using your already-signed-in Google account.
  • activeTab / host permission for Google Slides: used so the extension only runs on the currently open Google Slides editor.

Data retention and deletion

Display settings and the user dictionary are kept until you uninstall the extension or clear your Chrome sync data. Ruby text boxes created via the write feature can be removed at any time using the panel's delete function, or through normal Google Slides editing (undo/delete).

Google user data (Limited Use)

The use and transfer to any other app of information received from Google APIs by this extension will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

  • Google Slides data is used only to provide the user-requested feature (writing and removing furigana text boxes).
  • The data is never sent to or stored on a developer-operated server, and is never sold, shared, or transferred to third parties.
  • It is never used for advertising (including personalized ads), user profiling, or provided to data brokers.
  • No humans, including the developer, read this data; all processing happens inside your own browser.

Third-party sharing

We do not sell or share any information processed by this extension with third parties.
